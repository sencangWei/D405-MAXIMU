# UMI 手动夹爪磁编码器交接（更新于 2026-08-24）

## 已确认的产品定义

- 用户实测/给定机构名义半径：`25.15 mm`。
- 夹爪完全张开时，两软垫内侧的空载间距为 `66.90 mm`，并定义双边闭合行程为
  `0 mm`。
- 从完全张开向闭合方向运动时，夹合距离为正并逐渐增大。
- 这是手动 UMI 夹爪，不是电机定位或尺寸计量装置。原始绝对角和归一化开合比例是
  权威状态；毫米值只表示空载软垫间距估计，夹住器械后不能当作器械真实尺寸。
- 必须区分：
  - `dual_closing_distance_mm`：两个夹爪从完全张开开始合计闭合的距离；
  - `single_jaw_travel_mm`：单边行程，等于双边闭合距离的一半；
  - `estimated_no_load_gap_mm`：当前空载软垫间距估计。

## 已完成的判定

- 机构名义半径 `25.15 mm` 只保留为机械信息。实测中间点不符合固定半径
  `r*theta`，产品换算使用闭合/张开两条分段线性曲线。
- STM32 63 字节链路 10 秒台架通过：约 `399.755 Hz`、编码器有效率 `100%`、CRC、
  计数器间断和队列溢出均为 `0`。
- 完整闭合/张开扫程方向正确且没有 360° 回绕；扫程前后完全张开角只差
  `0.036°`，没有发现磁铁滑移。
- 同一开口从闭合和张开方向接近存在约 `0.54–1.29°` 回差，因此换算保留两条方向
  曲线。软垫接触后的角度还随手力变化，零间距只作为夹紧端钳位。
