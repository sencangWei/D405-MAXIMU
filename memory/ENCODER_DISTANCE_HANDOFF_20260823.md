# 磁编码器夹合距离交接（2026-08-23）

## 已确认的产品定义

- 用户实测/给定机构名义半径：`25.15 mm`。
- 夹爪完全张开定义为夹合距离 `0 mm`。
- 从完全张开向闭合方向运动时，夹合距离为正并逐渐增大。
- 必须区分：
  - `closing_distance_mm`：从完全张开开始累计的夹合行程；
  - `jaw_gap_mm`：夹爪当前剩余开口。

## 明日标定前不得提前假定的内容

- `25.15 mm` 目前是名义几何值，还不是签发后的有效半径。
- 只有机构输出确实是恒定半径圆弧长度时，才能直接使用
  `closing_distance_mm = 25.15 * delta_theta_rad`。
- 若夹爪输出是转臂投影、弦长或连杆/滑块运动，必须按真实机构几何建立
  `closing_distance_mm = f(delta_theta)`，不能直接使用 `r * theta`。
- 照片中黑色转臂轴心附近的银灰色圆片外观像磁铁，但照片不能确认磁化方向、
  与传感器芯片同轴度或工作间隙；这些要通过侧视尺寸和编码器诊断确认。

## 明日最小标定/验收流程

1. 夹爪完全张开并靠稳机械止挡，重复到位至少 5 次，记录绝对角
   `theta_open` 和零点重复性。
2. 缓慢走完整行程，确认角度方向、跨零回绕、无跳变和磁场诊断正常。
3. 根据机构形式选择圆弧或连杆几何模型，以 `25.15 mm` 为名义半径。
4. 用卡尺在至少 5 个分散位置测量夹合距离，并从张开、闭合两个方向分别接近，
   只做模型误差和回差验证。
5. 如果几何模型满足产品误差门，单台只保存 `theta_open`；若不满足，再拟合
   有效半径、零偏或单调查表，禁止在没有量具真值时调参数。
