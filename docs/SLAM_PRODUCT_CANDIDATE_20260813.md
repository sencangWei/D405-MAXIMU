# D405 + 外置IMU SLAM产品候选报告（2026-08-13）

## 结论

当前版本是**产品候选，不是客户最终交付版**。

它已经实现不读取人工终点答案的自动回环，并在两个独立闭环录制上把后验首尾距离做到1cm以内；真实升降反例没有误回环，也没有被压平。当前仍缺未参与开发的隐藏真值数据集、完整动作矩阵和深度/平面辅助，因此不能对客户承诺“所有场景稳定小于1cm”。

## 当前产品链路

```text
D405双IR 1280x720@30fps + KT-EX9-2 IMU 400Hz
    -> 固定td=-0.0117s的VINS局部里程计
    -> 原子双IR关键帧包
    -> DBoW历史候选（排除最近90个关键帧）
    -> 左IR RANSAC + VINS 3D/PnP + 右IR独立几何验真
    -> 连续4帧命中同一历史关键帧并通过修正一致性检查
    -> 3cm地图修正安全门
    -> 重力对齐4DoF位姿图优化
```

- `/odometry`：连续局部VIO，供控制或低延迟消费者使用。
- `/odometry_rect`：全局地图修正轨迹，回环时可能发生受控跳变。
- 任何人工首尾约束脚本只保留为诊断工具，不进入生产链路。

外部AprilGrid开发真值（SE(3)无尺度对齐，未触发回环）：

- 平移ATE RMSE：8.13mm；中位数5.93mm；P95 13.30mm。
- 约1秒RPE平移RMSE：3.83mm；旋转RMSE：0.285°。
- Z RMSE：6.10mm；Z绝对误差P95：11.75mm。
- 位置轨迹决定的全局SE(3)对齐下，旋转ATE RMSE为3.17°；但位置对齐与姿态对齐的全局旋转相差3.15°。改用姿态本身消除全局旋转自由度后，旋转ATE RMSE为0.319°，对应平移ATE RMSE为8.41mm。该差异说明原3.17°主要是评测坐标系对齐歧义，不应拿来修改SLAM外参；隐藏集仍需同时报告两组指标。

## 自动失效边界

- 少于90个关键帧的短时重访不视作场所回环，避免把普通跟踪或升降中的相似画面误认为闭环。
- 左右IR、RANSAC、3D/PnP或连续一致性任一失败即拒绝回环。
- 融合地图修正大于3cm时拒绝执行，本地VIO继续输出。
- 自动验收拒绝关键帧/估计器队列丢失、覆盖率低于98%、异常地图跳变和真实升降Z保留低于90%的版本。

当前离线C++回放能完整处理上述60秒开放序列，但该轮墙钟耗时约105秒；因此现阶段证明的是离线完整性，不是全场景稳定实时30fps。实时吞吐仍是交付前独立性能门槛。

## 尚未完成的客户交付门槛

1. 采集并冻结未参与调参的隐藏外部真值集，覆盖直线、L形、自由运动、闭环、水平、真实升降、原地旋转和快速手持，多轮统计ATE、RPE、每米漂移率、Z误差、误回环/漏回环率和失败率。
2. 实现有质量门控的Depth/平面软因子；平面差或真实升降时自动关闭，禁止无条件压平。
3. 验证长序列、多回环和开放轨迹。完全开放且从不重访的场景仍会累计漂移，若产品要求长期绝对位置，必须加入UWB、GNSS、AprilTag地图、激光雷达或其他全局观测。
4. 处理VINS-Fusion GPLv3商业分发合规。

因此当前可表述为：“在现有两组独立闭环开发/验证数据上，无人工提示自动回环达到4.53–6.71mm首尾一致性”；不能表述为“所有客户场景绝对精度小于1cm”。
