# D405 + 外置IMU SLAM产品候选报告（2026-08-13）

## 结论

当前版本是**产品候选，不是客户最终交付版**。

它已经实现不读取人工终点答案的自动回环，并在两个独立闭环录制上把后验首尾距离做到1cm以内；真实升降反例没有误回环，也没有被压平。当前仍缺未参与开发的隐藏真值数据集、完整动作矩阵和深度/平面辅助，因此不能对客户承诺“所有场景稳定小于1cm”。

## 当前产品链路

```text
D405双IR 1280x720@30fps + KT-EX9-2 IMU 400Hz
    -> 固定td=-0.0117s的VINS局部里程计
    -> 原子双IR关键帧包
    -> DBoW历史候选（排除最近90个关键帧）
    -> 左IR RANSAC + VINS 3D/PnP + 右IR独立几何验真
    -> 连续4帧命中同一历史关键帧并通过修正一致性检查
    -> 3cm地图修正安全门
    -> 重力对齐4DoF位姿图优化
```

- `/odometry`：连续局部VIO，供控制或低延迟消费者使用。
- `/odometry_rect`：全局地图修正轨迹，回环时可能发生受控跳变。
- 任何人工首尾约束脚本只保留为诊断工具，不进入生产链路。

| `20260813_000933` | 带升降强闭环交叉验证 | 1 | 99.32% | **6.71mm** | 100%（279.17mm） | 0 |

闭环首尾距离只在回放结束后评分，未传入算法。真实升降段中一条约5.1cm的不可信地图修正被安全门拒绝。

外部AprilGrid开发真值（SE(3)无尺度对齐，未触发回环）：

- 平移ATE RMSE：8.13mm；中位数5.93mm；P95 13.30mm。
- 约1秒RPE平移RMSE：3.83mm；旋转RMSE：0.285°。
- Z RMSE：6.10mm；Z绝对误差P95：11.75mm。
- 位置轨迹决定的全局SE(3)对齐下，旋转ATE RMSE为3.17°；但位置对齐与姿态对齐的全局旋转相差3.15°。改用姿态本身消除全局旋转自由度后，旋转ATE RMSE为0.319°，对应平移ATE RMSE为8.41mm。该差异说明原3.17°主要是评测坐标系对齐歧义，不应拿来修改SLAM外参；隐藏集仍需同时报告两组指标。

## 自动失效边界

- 少于90个关键帧的短时重访不视作场所回环，避免把普通跟踪或升降中的相似画面误认为闭环。
- 左右IR、RANSAC、3D/PnP或连续一致性任一失败即拒绝回环。
- 融合地图修正大于3cm时拒绝执行，本地VIO继续输出。
- 自动验收拒绝关键帧/估计器队列丢失、覆盖率低于98%、异常地图跳变和真实升降Z保留低于90%的版本。
- 运行看门狗同时订阅`/odometry`与`/odometry_rect`，不读取真值或终点；检测话题缺失/停流、非有限位姿、时间戳倒退、双流时差和异常地图跳变，并发布标准`/slam/diagnostics`与JSON `/slam/health`。数据完整性/跳变故障会锁存，话题暂时缺失或停流允许恢复；离线验收把同一判定快照封入运行报告。

独立实时部署命令：

```bash
source /opt/ros/humble/setup.bash
python3 scripts/slam_runtime_watchdog.py \
  --output-json reports/live_slam_health.json
```

只有状态为`SLAM_HEALTHY`且`product_usable=true`时，下游产品才可使用当前轨迹；`STARTING`、`SLAM_FAILED`或`INFRASTRUCTURE_BLOCKED`均不得对外宣称轨迹有效。

当前离线C++回放能完整处理上述60秒开放序列，但该轮墙钟耗时约105秒；因此现阶段证明的是离线完整性，不是全场景稳定实时30fps。实时吞吐仍是交付前独立性能门槛。

Depth平面因子仍处于离线原型阶段：只有局部平面精度/面积、世界重力方向、法向聚类和平面距离聚类全部通过才允许软约束。`001100`检测到的主平面不是水平面，系统已自动关闭约束；当前版本不会为了好看而把Z压成0。

四流原生DB3曾有离线I/O瓶颈：5分钟只处理450/1350 VINS帧。现在可一次性生成只含双IR图像与设备metadata的派生DB3，不修改原始录制。`001100`中缓存2.58GB（原包7.71GB），45秒数据约47秒完成回放，VINS收到1350对图像、输出1339个位姿，回环传输与估计器队列均0丢失；缓存生成本身耗时543秒，后续还可转为采集时并行落盘。

## 尚未完成的客户交付门槛

1. 采集并冻结未参与调参的隐藏外部真值集，覆盖直线、L形、自由运动、闭环、水平、真实升降、原地旋转和快速手持，多轮统计ATE、RPE、每米漂移率、Z误差、误回环/漏回环率和失败率。
2. 实现有质量门控的Depth/平面软因子；平面差或真实升降时自动关闭，禁止无条件压平。
3. 验证长序列、多回环和开放轨迹。完全开放且从不重访的场景仍会累计漂移，若产品要求长期绝对位置，必须加入UWB、GNSS、AprilTag地图、激光雷达或其他全局观测。
4. 处理VINS-Fusion GPLv3商业分发合规。

客户交付状态由可执行门禁生成，不再靠文字判断：

```bash
python3 scripts/validate_slam_product_release.py
python3 scripts/validate_slam_product_release.py --require-complete
```

- 第一条只检查当前开发/验证候选证据，当前输出为 `CANDIDATE_PASS`，并明确 `customer_release_complete=false`。
- 第二条是客户完整交付门禁。它要求八类动作每类至少3条冻结隐藏盲测、每条均预先声明是否应回环并提供哈希保护的外部真值和评测报告，同时检查ATE、平移/旋转RPE、每米漂移率、Z误差、姿态误差、闭环一致性、误回环、覆盖率、丢帧和失败率。当前会正确返回 `NOT_READY`，不会把开发集结果误报为客户可交付。
- 阈值已经冻结在 `config/slam_product_datasets.json`，真值只进入评分器，绝不进入SLAM。

因此当前可表述为：“在现有两组独立闭环开发/验证数据上，无人工提示自动回环达到4.53–6.71mm首尾一致性”；不能表述为“所有客户场景绝对精度小于1cm”。
