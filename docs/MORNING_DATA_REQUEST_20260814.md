# 明早最少补充数据清单

先看`reports/declared_loop_regression_overnight/summary.json`：如果四组历史闭环各3轮全部通过，就不需要重录闭环调试数据；若某组失败，继续用同一封存数据定位和修算法，不能通过换一条更容易的数据掩盖失败。

## 回环产品验收（无外部真值）

每条60秒，使用现有RSUSB双IR30fps＋IMU400Hz零丢帧采集：

当前四组历史闭环只用于开发/验证回归，不再补录同类调试数据。进入最终独立验收时再采：

1. 水平闭环3条：起终点位置和镜头朝向都相同，终点静止3秒。
2. 带真实升降闭环3条：途中升降20–40cm，起终点位置和朝向相同，终点静止3秒。
3. 相似但不闭环负样本至少1条用于冻结PnP安全阈值；最终误回环统计需3条。终点离起点至少20cm，但画面仍可能相似。

起终点重合声明只在录制前写入清单，算法完成后评分；不传给VINS、候选检索或位姿图。

## 客户绝对精度报告（必须外部真值）

仅靠“起终点重合”只能测闭环一致性，不能测整条路径ATE/RPE。客户报告仍至少需要：

1. AprilGrid全程可见、动捕或外部定位中的一种真值来源。
2. 八类动作各3条：直线、L形、自由运动、水平闭环、升降闭环、非闭环升降、原地旋转、快速手持。
3. 每条真值包含时间戳、位置和姿态；真值文件先哈希冻结，只允许在SLAM完成后评分。

## Depth/Z正样本

现有Depth库存只观测到墙面，没有通过重力门的水平面。若要验证Z软约束，再录1条四流数据：镜头能持续看到桌面或地面，先水平移动、再真实升降20–30cm、最后回到原高度。该数据用于证明“稳定平面时减小Z漂移、真实升降时不被压平”。
