# 调查结论

- 当前稳定主线是 VINS 双 IR + IMU；小于 1m 的实测表现优于现有 ORB RGB-D-Inertial。
- 当前人工闭环工具依赖操作者确认，不具备产品自动回环语义。
- 产品自动回环必须输出真实几何相对位姿并优化 SE(3)，不能只把终点平移回起点。
- RSUSB 采集链路已在 GitHub 分支 `backup/rsusb-capture-20260812` 备份，提交 `42f280e`。
- 当前 `/home/robot/ros2_ws/src/vins_fusion_ros2` 没有 `loop_fusion`，但已发布 `keyframe_pose` 和 `keyframe_point`，具备对接官方回环模块的核心数据接口。
- 官方 VINS-Fusion 自带视觉回环：DBoW2 场所识别、关键帧几何连接、Ceres 位姿图优化；产品方向应移植/复用该模块，而不是扩展人工闭环脚本。
- 官方项目为 GPLv3。若随商业产品分发，需要在产品许可方案中处理 GPLv3 对应义务；技术验证与商业合规需同时推进。
- 找到 `zinuok/VINS-Fusion-ROS2` 的 ROS2 Humble 端口线索，下一步核验其 `loop_fusion` 完整性与本地端口兼容性。
- 2026-08-13 产品审计：当前自动回环节点只订阅 `image0_topic`，因此 VINS 局部里程计虽使用双 IR，回环几何验真本身仍是单路左 IR；后续必须增加左右 IR 同步证据后才能满足产品方案。
- 当前 loop_fusion 后端是官方重力对齐 4DoF（x/y/z/yaw）图优化，不是通用 SE(3)。这与手持重力对齐 VIO 可以兼容，但文档和验收必须写真实能力。
- 当前最好结果 2.62 cm -> 1.21 cm 是同一强闭环会话的首尾一致性改进，不是 ATE；现有报告明确标记 absolute accuracy 未测量。
- 当前可作为基线的证据：RSUSB 60 s 数据三路相机 30 fps 零丢帧、IMU 400 Hz 正式段零丢帧；VINS 固定 td=-0.0117，自动回环不读取人工终点答案。
- 当前最重要的产品缺口依次是：数据集隔离/盲测评测、双 IR 回环验真、Z 软约束与质量门控、SLAM 失效检测、多数据多轮统计。
- 双 IR 第一版使用可靠大队列直接订阅原始图像，会通过DDS反压VINS输入；升降回归只生成839/1743位姿。回环图像改为Best-Effort有限队列、离线排空延长后，同段恢复1743/1743且0回环接受。生产原则：回环可漏掉候选，但绝不能阻塞局部里程计。
- Best-Effort原始图像虽保护VINS，却会使左右IR关键帧错配或丢失；最终产品边界必须是估计器生成的原子关键帧包，而非回环端重新同步原始30fps图像。
- 当前无提示闭环最可信结果是`000933`的1.136cm静态段一致性；它不是ATE，也不能据此宣称客户精度<1cm。现阶段应保持保守冷却参数，并转向隐藏数据与外部真值，而不是继续在同一开发集拟合。
- `151212`真实升降完整回归0接受，说明当前五帧连续一致性门槛能拒绝仅在结尾短暂相似的升降序列。
- 测试过程自身必须隔离ROS图：残留同名发布节点会生成表面合法、实为多发布者叠加的轨迹；产品验收脚本已增加残留节点硬失败。
- 四帧确认候选若仅排除50个关键帧，会在真实升降`151212`上接受current=98/matched=43的短时相似画面。把场所回环时间排除扩大为90关键帧后，该段0接受，同时`155408`和`000933`闭环仍分别为4.53mm和6.71mm。
- 3cm地图修正安全门能拒绝升降段后部约5.1cm的不可信修正；闭环正例的有效修正约2.1cm，不受影响。
- 现有外部AprilGrid开发真值：SE(3)无尺度对齐ATE平移RMSE 8.13mm、RPE平移RMSE 3.83mm/约1秒、Z RMSE 6.10mm；旋转ATE RMSE 3.17°仍是明确短板。
- 开放/近闭环`121306`在干净环境重跑得到99.03%覆盖、0回环接受、0队列丢失，纠正了旧运行仅68%覆盖的环境性失败；但60秒数据墙钟约105秒，属于离线完整通过，不是稳定实时性能通过。
