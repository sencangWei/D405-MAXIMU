# ROS 2 Jazzy 迁移交接计划

## 目标

把 D405 + KT-EX9-2 的完整 SLAM/标定工作转移到另一台 ROS 2 Jazzy 电脑，保留源码、Git 历史、未提交改动、原始数据、标定、实验报告、长期记忆、依赖信息和后续任务，且可用清单与 SHA-256 验证没有漏拷或损坏。

## 成功标准

- [x] 枚举所有项目、定制依赖、标定和原始数据路径及容量。
- [x] 对每个 Git 仓库同时保留完整目录、状态、提交/标签清单、bundle 与 dirty patch。
- [x] 生成新 Codex 可直接读取的中文交接文档，明确当前有效结论、失败候选、未完成项和 Jazzy 风险。
- [x] 生成复制到移动固态的脚本，默认不删除源数据、不在旧盘重复一份大数据。
- [x] 生成传输清单和复制后 SHA-256/数量/容量校验工具。
- [x] 在本机对脚本做静态/小样本验证，输出明确的复制命令和所需移动盘容量。

## 阶段

1. **审计源资产** — `completed`
2. **编写交接文档和迁移清单** — `completed`
3. **编写安全复制与校验脚本** — `completed`
4. **验证交接包并给用户复制命令** — `completed`

## 约束

- 不重启旧电脑，不安装系统包，不启动硬件运动。
- 不覆盖用户数据；经用户后续明确授权后，只将冻结清单中的已替代旧录制原子移入项目外可恢复隔离区，不在 SSD 整包校验前永久删除。
- 大 DB3/视频不在旧电脑本地重复打包；直接 rsync 到移动固态。
- Humble 的 build/install/log 和二进制扩展不能当作 Jazzy 可运行产物；源码和版本证据必须保留，Jazzy 端重新构建。
- 交接不能把失败的 IMU 手工陀螺矩阵、陈旧 7.36ms 时间偏移或强制压平 Z 当作有效配置。
