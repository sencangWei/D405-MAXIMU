## ① 定点看帧：B 类超标时刻到底拍到了什么（`bframes.py`，52 帧 + `frames0919/` 5 张接触表）

采样：最长超标段 起点/¼/½/¾/峰值 + 同 take 误差最小处做对照。

| take | 超标时刻 | 对照帧 |
|---|---|---|
| **batch5/g3** | **空白木桌面**，相机**几乎静止 1.8–3.2 mm/s** | **瓶子充满画面**（纹理丰富） |
| **v10b2/g1** | **显示器充满画面**（终端在滚 + D405 自己的实时预览） | 桌面杂物 |
| v10/g2 | 段中=空白桌面 | 显示器+红碗 |
| A 类 / PASS 那条 | **看不出任何区别** | — |

⇒ **两个 B 类 take 的画面结论互相矛盾**（一个纹理太少、一个纹理太多）⇒「低纹理」不是统一解释。

## ② ★ 上数之后画面【不解释】误差（`btrace.py`，10 take × 1743 帧）

排除「动作」混杂：**只在真值线速度 < 15 mm/s 的帧内部分层**。

```
静止帧内 corr(纹理, 误差)   中位 +0.030   为负的 5/10
低纹理误差 − 高纹理误差     中位 −0.19mm  低纹理更差的 4/10
静止帧内 corr(画面变化,误差) 中位 +0.197   为正的 9/10   ← 唯一略正，幅度很小
动态画面误差 − 静态画面误差  中位 −0.08mm  动态更差的 3/10
```

⇒ **纹理不是解释**。唯一大声的例外是 `batch5/g3`（低纹理 12.65 vs 高纹理 3.90mm，
`corr(orb,err) = −0.457`），就是 ① 里那一个。

> ⚠ **口径警告**：整条 take 的相关与定点看帧**会打架**。v10b2/g1 的显示器时段只占全长 3%，
> 被整条相关冲掉，但定点看帧时最醒目。**两个结论都要报，别只挑一个。**

## ③ ★★ `batch5/g3`：开头 7.53s 相对后面被挪开 15–18mm，**最上游就已经是**

误差剖面（**逐帧打出来**的，不是抽样）：`t∈[0,7.6s]` 平在 12.0–13.9mm；
`t≈7.6→8.13s` **平滑过渡 ~0.7s**（12.04→11.3→10.35→9.11→7.84→7.09→6.16）；
`t≈8.13s` 触底 ~6.1mm 后回升。

段间缝合（在 `t−t₀=7.53s` 切开，两段各自 `rigid_align` 到真值再比两个变换）：

```
链              头残差   尾残差   段间互差   夹角
①frames(前端原始) 3.83    12.35    17.69mm   8.77°   ← ★ 还没经过 [6/8]，就已经是
②imu_metric      3.83    12.35    17.69mm   8.77°
③graph           4.25    11.04    15.05mm   8.47°
④fused(产品)      0.83     4.70    15.07mm   2.77°
```

⇒ **这条内部不一致是前端造的**；[6/8]/[7/8]/[8/9] 都没制造它，
融合把两端残差从 3.83/12.35 压到 0.83/4.70，**但没消掉那 15mm 互差**。

**测量可信**（先排退化）：两段空间展布 100mm / 400mm（不是点）；奇异值比
头 `1.000/0.144/0.086` vs 真值头段 `1.000/0.175/0.109` ⇒ 不共线不共面、朝向受约束。

> ⚠⚠ **本条早先版本有三处错，已更正，别再引用旧说法**：

## ④ 段间位移【不是】判别量（`segment_stitch.json`，18 cell）

切点必须**无监督**（挑切点=循环论证）：用**前端自己的开头关键帧空洞**。

```
n=18  段间位移 中位 4.46mm  范围 3.07–15.07mm
      corr(段间位移, max) = +0.442          ← 中等，是【贡献者】不是全部解释
      达标那 1 个 cell = 4.55mm             ← 正好在中位 ⇒ 【不是判别量】
      前段残差 1.17 vs 后段 4.21mm          ← 18/18 前段更干净（静止，正常）
```

**融合修不修得好这段差别很大**：`v11b3/g2` graph 18.1 → fused **4.55mm**（修好 ⇒ 达标）；
`batch5/g3` graph 15.0 → fused **15.07mm**（**没修**）。
切点前提「每条 take 都是静止起手」**已被 ③ 否掉** —— 空洞本身是真的（6.5–15.8s），
但成因不是"静止"，用它当无监督切点这件事本身仍然成立。

## ⑤ 工具口径（踩过的坑）

- `d405_frames.csv` 行 ↔ db3 消息**逐行对应**（差 0/1 行 = 33ms，看段无影响）；
  轨迹 `t_sec` 经 provenance 的 `epoch_minus_monotonic_s` 落到 `color_mono`。
- db3 话题号**全部会话一致**：**69=RGB(YUYV) / 72=IR1(8UC1) / 75=IR2(8UC1)**。
- `cdr_string` **必须 `o += n`**（漏了会导致高 6 字节 ⇒ height 解析成 `0x6f6c6f43`＝"Colo"）。
- 双 IR 是**单通道**，按 RGB 三通道 reshape 会报
  `cannot reshape array of size 921600 into shape (720,1280,3)`。
- `ORB.detect()` 返回 `(keypoints, descriptors)`，`[0]` 已是列表（`len()` 别再加 `[0]`）。
