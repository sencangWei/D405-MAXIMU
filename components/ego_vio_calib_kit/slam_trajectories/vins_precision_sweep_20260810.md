## 结论

1. **committed 配置 (e239352, tag vins-dual-ir-stable-20260810) 已是本数据集经验最优点。**
   td=-0.0117 (08-08 Kalibr) + est_td:0 + shift=0 单次补偿; iter=8 / parallax=10 / max_cnt=400 / min_dist=20 / Allan 噪声 / g_norm=9.805 / WINDOW_SIZE=10 —— 全部 26+ 次变体实验无一改进, 部分更差或引入偶发坏跑。
2. **可达精度**: 闭环 0.7–2.2cm (均值 ~1.4cm), zspan <2.6cm, 重力面倾斜 <1°, z 平面 RMS <3mm, 矩形尺度 100–105%。
3. **残留误差是根本性限制**, 非配置可调:
   - 53×43cm 慢速回路视差弱 + IMU 激励弱 → 初始化/偏置可观测性不足 → 运行间噪声 ±1.5cm。
   - 与 ORB RGB-D 的 "小回路极限" 同源 (见 orb-rgbd-inertial-status 记忆)。
4. **进一步提高需要更大回路** (边长 1.5–2m 重录) 或深度代码改造 (边际化策略), 配置层已无油水。
5. 教训与 ORB 一致: 偏离调好的稳定参数 ("更多"迭代/窗口/特征) 不带来精度, 只会增加计算或引入坏跑。
