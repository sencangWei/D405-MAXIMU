# 当前 USB 转 TTL 链的相机—IMU联合标定候选

适用条件：D405 与 IMU 已刚性锁紧且之后不再改变相对位置；STM32 尚未到货，IMU仍通过
产品档案绑定的 USB 转 TTL 串口读取。

## 运行命令

```bash
cd /home/robot/ego_vio_calib_kit
./camera_bench_05_camera_imu.sh D405_260322273737
```

命令会自动校验并使用：

- 最新的、绑定当前产品且结果为 PASS 的 D405 双目候选；
- 原始 IMU（30 姿态加速度矩阵不加载）；
- 满足6小时、400 Hz和静止门的Allan噪声数值。现有Allan报告的传输失败项会原样绑定到
  证据中，仅允许作为本次TTL候选的Kalibr噪声先验，不会被改写成正式PASS。

## 操作方法

1. 把 AprilGrid 刚性固定在墙面或竖直平板上，不要在采集过程中移动标定板。
2. 手持并移动整个 D405＋IMU支架；禁止单独扭动相机或IMU。
3. 第一份采集按画面依次完成 X/Y/Z平移和 pitch/roll/yaw旋转，动作连续、缓慢，始终让
   标定板清晰可见。
4. 第一份求解完成后，第二份从头独立重复，不要只复现第一份的一小段动作。
5. 两份结果自动比较旋转、平移、时间偏移、Kalibr残差和相机正式窗口丢帧。

默认每个动作阶段20秒，每份约120秒；两份之间会分别运行Kalibr，求解时间不算在采集
时长中。需要中止时使用 Ctrl+C；中止数据不能通过候选门。

## 结果边界

候选 PASS 表示当前TTL链下两次联合标定重复性及残差通过。空间外参在机械安装不变时可
继续作为候选；`td` 只属于当前USB转TTL时间链。STM32到货并切换63字节MCU时间戳后，
必须重新做时间链A/B，当前 `td` 不得直接写入最终产品配置。
