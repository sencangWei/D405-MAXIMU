# 明天开始标定：现场清单

## 先说清时间安排

完整六步不能在同一天结束：第 2 步正式 Allan 采集默认 16 小时，产品门槛要求至少
15 小时。明天可以完成建档和第 1 步，然后启动第 2 步过夜；第 2 步 PASS 后才能做
第 3～5 步。第 6 步还必须等第 1～5 步候选参数真正接入冻结 VINS 运行链后再采，当前
脚本会主动返回 `BLOCKED`，不会误用旧 `-11.7 ms` 和旧外参。

## 上电前

1. D405、IMU、STM32/USB 转串口和线缆装到最终支架；D405 与 IMU 之间必须完全锁紧。
   整套支架倾斜没有问题，标定期间不能改变两者相对位置。
2. 使用已有、以前标定跑通的 `6×6` AprilGrid。配置固定为单 tag `35.2 mm`、净间距
   `10.56 mm`、`tagSpacing=0.3`；不需要重新生成或打印。
3. 用主板直连 USB 口，关闭可能抢占相机或串口的采集/VINS 程序。准备稳定供电，禁止
   USB Hub 省电和采集中途重插。
4. 给产品确定唯一编号，例如 `P001`。所有原始数据和报告都进入
   `calibration_sessions/P001/`，失败重采不会覆盖旧 attempt。

## 设备接好后的唯一预检

```bash
cd /home/robot/ego_vio_calib_kit
ls -l /dev/serial/by-id/
./calibrate_init.sh P001
```

必须只识别到一台 D405 和一个稳定 `/dev/serial/by-id/...` IMU 端口。`PASS` 后继续；
`BLOCKED` 时不要手改成 `/dev/ttyUSB0`，先排查接线、权限或设备重复。

## 第一天

### 1. 静态 bias（约 10 分钟）

```bash
./calibrate_01_imu_static.sh P001
```

整机按工作姿态刚性放稳，线缆不拉扯；不要求水平。前 2 分钟预热，后 8 分钟正式
统计。只在结果为 `PASS` 时进入下一步。

### 2. Allan 噪声（默认 16 小时，过夜）

```bash
./calibrate_02_imu_noise.sh P001
```

放在恒温、无振动、不会被碰到的位置，禁用休眠并保持供电。期间不能移动、断电、重插
或关闭终端。少于 15 小时不会形成正式产品噪声参数。

## Allan PASS 后

### 3. 任意 30 姿态 IMU 内参

```bash
./calibrate_03_imu_intrinsic.sh P001
```

按提示移动整套刚体；支架倾斜没关系。每个姿态放稳后按回车。前 20 个用于拟合，后
10 个仅验证，脚本会拒绝不稳定姿态。

### 4. D405 双 IR 内参/双目外参

```bash
./calibrate_04_d405_stereo.sh P001
```

固定整机，只移动 AprilGrid。命令会明确采两份：第一份进入 Kalibr 求解，第二份是
完全独立的留出集。留出集自动检查至少 40 个有效同步视角、目标中心覆盖左右九宫格、
整流后纵向极线误差 P95 `≤1 px`。

### 5. 相机—IMU 外参和时间偏移

```bash
./calibrate_05_camera_imu.sh P001
```

固定 AprilGrid，移动锁紧后的 D405＋IMU 整体，覆盖 XYZ 平移和 roll/pitch/yaw。命令
采两份完全独立数据并互相比较；不会复制旧外参或旧 `td=-11.7 ms`。

### 6. 世界 Z

```bash
./calibrate_06_world_z.sh P001
```

暂时不要把默认实时模式的结果签成新产品 Z 标定。只有当第 5 步报告 PASS，并完成“新
相机内参＋新相机/IMU 外参＋新 td＋新 IMU 校正”候选运行链注入及 10 秒冒烟后，才采
3 条平面正例和 2 条真实升降负例。当前命令对未完成该连接的现场会返回 `BLOCKED`。

## 每一步的停止规则

- `PASS`：保留报告，进入下一步。
- `FAIL`：保留失败证据，按报告原因重做当前步。
- `BLOCKED`：设备、身份、前置结果或正式运行链不完整；不得跳步，也不得复制历史
  参数把状态改成 PASS。
